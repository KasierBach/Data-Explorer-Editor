## Maintenance rule

When a follow-up is fixed, link its tests/decision and update the affected bilingual topic plus source-backed facts. Do not remove a limitation solely because an adapter method, UI toggle, marketing label or test mock exists. A passing metadata readback is not certification of an engine/cloud matrix, an end-to-end security boundary or a retention guarantee.
